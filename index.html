Panduan Gratis Hosting

Cara Upload Website ke GitHub Pages

Dapatkan link website Anda secara online (contoh: namaanda.github.io) tanpa biaya hosting selamanya!

1

Buat Akun & Repository GitHub Baru

Daftar di GitHub.com, klik tombol tombol "New" untuk membuat repositori baru. Beri nama misal cv-saya atau undangan-pernikahan.

2

Upload File Kode HTML

Pilih opsi "uploading an existing file". Pastikan file kode utama Anda dinamai persis index.html, lalu klik "Commit Changes".

3

Aktifkan Fitur GitHub Pages

Masuk ke menu tab Settings repositori > Pilih menu Pages di bagian navigasi kiri. Pada opsi Branch, ubah dari None menjadi main (atau master) lalu klik Save.

4

Selesai & Bagikan Link Website!

Tunggu sekitar 1–2 menit, GitHub akan memberikan URL live website Anda seperti https://username.github.io/cv-saya secara gratis!
